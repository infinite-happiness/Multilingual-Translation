Multilingual-Translation: how to run
====================================

This project uses pnpm only. Run all commands from the project root.

1. Install dependencies (first time, or after package.json changes)

   pnpm install


2. Development server (hot reload)

   pnpm dev

   Opens at http://localhost:3000


3. Production build (type check + build into the dist/ folder)

   pnpm build


4. Preview the production build

   pnpm preview

   Opens at http://localhost:3000

   This serves the dist/ folder, so run "pnpm build" first.


Notes
-----
- Dev and preview both use port 3000 (set in vite.config.ts), so they
  cannot run at the same time. Stop one (Ctrl+C) before starting the other.
- If port 3000 is already taken, Vite picks the next free port and prints
  the actual address in the terminal.
